# Roadmap

The project moves through phases, planned one at a time. Only the current phase has milestones. Each milestone is a stage of the phase, and one GitHub milestone. It has a target date, completion criteria, and go criteria the product manager checks before moving on. [`issue-workflow.md`](issue-workflow.md), "Milestones", explains how a milestone is reviewed.

ClearTXT is live at `https://icelsupreme.github.io/ClearTXT/`.

## Phase: Post launch improvement (current)

The phase ends when its last milestone's review is a go.
